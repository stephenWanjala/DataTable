class CellEditController(source)

Handle given to a column's DataTableHeader.editorContent, for editors that are not plain text.

A custom editor renders whatever control it likes — a dropdown, a date picker, a lookup field — and calls commit or cancel when the user is done. It is composed in place of the cell's normal content and is expected to take keyboard focus itself.
