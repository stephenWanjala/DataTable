DataTableDensity

enum class DataTableDensity : Enum<DataTableDensity> (source)

Density presets that control vertical and horizontal padding for rows and headers.

Density sets padding, and DataTable's default row height is derived from it — DataTableDefaults.rowHeight is this padding either side of a single line of body text. A row is that tall whatever its cells hold, so a column that wraps is clipped rather than allowed to make the row taller. Pass DataTable a larger rowHeight for cells that need one, or rowHeight = null for rows that grow to fit their content.
