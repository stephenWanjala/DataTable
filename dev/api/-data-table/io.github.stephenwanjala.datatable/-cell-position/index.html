CellPosition

@Immutable
data class CellPosition(val rowKey: Any, val columnKey: String)(source)

Identifies a single cell — the intersection of a row and a column.

The row is named by the key DataTable's itemKey produced for it and the column by its DataTableHeader.key, so a position survives sorting, filtering, and paging rather than pointing at whatever now sits at a given coordinate.
